# Results Directory

This directory stores outputs generated by the Real-Time Deepfake Video and Face-Swap Detection system.

## Outputs Stored Here

- **Annotated Videos**: Processed video files with bounding boxes, confidence score meters, and status badges (e.g., `results/output.mp4`).
- **Inspection Snapshots**: Video snapshots and frames captured during real-time analysis using the `S` key in the GUI (`screenshot_<timestamp>.jpg`).
- **Benchmark Reports**: Latency and throughput benchmark logs.
- **Evaluation Curves**: ROC-AUC plots, confusion matrices, and precision-recall graphs generated from `notebooks/deepfake_training.ipynb`.

> Media files (`.mp4`, `.avi`, `.jpg`, `.png`) stored in this folder are excluded from Git commits via `.gitignore`.
